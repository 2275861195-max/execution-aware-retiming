# Figures and editable sources

PNG files are GitHub previews; SVG files are scalable exports. Each conceptual diagram also has an editable `.drawio` source with sketch styling. Open it in [draw.io](https://app.diagrams.net/), then export a revised PNG/SVG after editing.

Regenerate the supplied aggregate plots and conceptual sources with `python scripts/make_meeting_figures.py` (requires matplotlib). Numeric curves are not hand-distorted. Sketch styling is confined to conceptual boxes.

The `pareto` filename is retained for the requested artifact layout; the figure shows observed operating points, not a demonstrated universal Pareto frontier. No error bars are invented.

Useful optional icon source: [Lucide](https://lucide.dev/), with its [license notices](https://github.com/lucide-icons/lucide/blob/main/LICENSE). No third-party icon asset is bundled here; retain the applicable notice if adding one. The public [draw.io MCP](https://www.drawio.com/docs/manual/generate/drawio-mcp-server/) also provides a shape-search interface. Simple scientific diagrams deliberately use editable geometric shapes rather than decorative logos.
