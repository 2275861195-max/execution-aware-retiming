# Research visual assets

This directory reserves space for validated project illustrations. The following assets are planned, not yet provided:

- **System overview:** frozen policy, chunk retimer, effective controller commands, and physical execution; mark hypothetical causal links explicitly.
- **Clock versus progress:** source-clock advancement beside realized motion and interaction milestones, with units and operational definitions.
- **Matched success/failure rollout:** aligned reference and accelerated videos with task, initialization, condition, outcome, and first-divergence annotation. Include representative counterexamples rather than only favorable cases.
- **Future project-page teaser:** a restrained summary figure derived from validated evidence, not an unmeasured performance claim.

Every released figure should identify whether it is schematic or empirical and include provenance, version, units, and a caption. Curated videos require verified success labels and permission to release. Raw videos, private data, model checkpoints, and server information do not belong here.
